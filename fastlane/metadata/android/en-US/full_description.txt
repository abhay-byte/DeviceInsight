DeviceInsight — the instrument for your phone. Measure everything. Label everything.

The screen is a sheet of drafting paper. The phone is the instrument.

Built to CALIPER — the language of laboratory equipment: a Braun multimeter, an HP oscilloscope, a numbered binder sheet. Paper, not glass. Hairlines, not shadows. Channels, not cards. Numerals dominate; chrome whispers. Tabular figures, tick scales and hatch patterns carry the signal. No blur, no gradients.

Three media, same instrument: Paper (warm light), Carbon (charcoal) and Blueprint (cyanotype). Ink carries layout; color belongs to data only. A bench tool machined for you — not a template dashboard.

CHANNELS — Every metric is a numbered channel with color + hatch + label:
CH-01 CPU solid · CH-02 MEMORY diagonal · CH-03 NETWORK cross-hatch · CH-04 POWER dots · CH-05 STORAGE vertical · CH-06 GPU horizontal. Thermal is a ramp — amber → vermilion → fault red — always with °C readout and zone.

№ 01 OVERVIEW — All channels nominal.
Four ReadoutTiles with 60 s pen-dot sparklines, peak-hold ticks and asymmetric rules. Tap → channel. Pull to re-ink. Warning = pulsing LED + fault red.

№ 02 ACTIVITY — Processor, Memory, Network, Power, Storage.
Processor: odometer frequency, CoreRail mixing bars with peak-hold ⌃ and Hz, ScopeTrace (engineering grid, square pens, pen-dot, crosshair min/max/avg) and thermal ramp (neutral/warm/moderate/severe/throttling).
Memory: HatchBar composition + hero 6.81/12 GB + top consumers ledger.
Network: dual-trace ScopeTrace (down channel / up ink) + ↓/↑ odometers.
Power: LinearGauge fuel strip with ticks, W/V/°C and discharge trace; charging = blinking needle.
Storage: HatchBar cadastral map + dotted legend; tap segment → partition.

№ 03 PROCESSES — Ledger → Dossier → SafetyLatch.
0142  com.android.chrome  4.2% 312 MB
     pid 22081 · 14:02:11 · ● foreground
Sticky sections (USER APPS / SYSTEM / SELF), 04d index, tabular CPU%/RSS without shift. Sort by CPU, FIND field. Tap → perforated Dossier with mini sparklines, uid/oom_adj/seccomp and clinical kill: drag SAFE→ARM (hatched rail, haptic), then KILL ⏻ unlocks. ABORT always available.

№ 04 DEVICE DOSSIER — Spec sheets + plates.
Dotted leaders — model ........... Pixel 8 Pro — plus line-art plates: FIG.1 cluster topology, display chain, camera map, sensor inventory with serif captions.
Eleven sheets: SYSTEM / CPU / DISPLAY / GPU / NETWORK / BATTERY / ANDROID / HARDWARE / THERMAL / STORAGE / SENSORS. Battery = fuel gauge + spec; Hardware = cameras/USB flat cards (focal/flash/OIS/ZOOM/AE/AWB, focus modes); Thermal = grouped ramp bars; Sensors = Motion/Position/Environment/Biometric strips; Storage = HatchBar + directory/mount rows. NOT FITTED = hairline strike + meta label. Tablet: two-pane.
